# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

See [AGENTS.md](./AGENTS.md) for the underlying AstroWind template documentation (commands, Tailwind v4 setup, config system, fonts, images, component patterns). This file covers how **this repo** differs: it is Supuni Dissanayake's personal portfolio built on AstroWind, deployed to Netlify (`https://supuni-dissanayake.netlify.app`).

## Commands

- `npm run dev`: dev server at localhost:4321
- `npm run build`: static build to `./dist/` (this is also the Netlify build command)
- `npm run check`: `astro check` + ESLint + Prettier. CI (`.github/workflows/actions.yaml`) runs `check` and then `build` on pushes and PRs to `main`, so both must pass.
- `npm run fix`: auto-fix ESLint + Prettier
- There is no test suite. To verify a change, run `check` and `build`.
- Node: `package.json` requires `>=22.22.3` (`.nvmrc` says `22`).

## Portfolio-specific architecture

### Projects collection (the main content)

- Projects are Markdown files in `src/data/projects/`, using the `projects` schema in `src/content.config.ts`. Required fields are `title`, `summary` and `stack`. Optional fields are `order`, `date`, `status` (`completed`|`ongoing`), `draft`, `category`, `role` (`built`|`contributed`), `image` and `links.{frontend,backend,repo}`.
- `getProjects()` in `src/utils/projects.ts` returns non-draft projects sorted by `order` (missing `order` sorts last, as 99). Cards render through `src/components/projects/Grid.astro` and `GridItem.astro`.
- Detail pages are generated by `src/pages/projects/[...slug].astro`.
- **Custom case-study pages:** `src/pages/projects/smartclinic.astro` and `mentora-mobile.astro` are standalone, hand-designed HTML pages with their own inline CSS and Google Fonts. They do not use the AstroWind layout or theme tokens. Their IDs are hard-coded in a `customPageIds` set in `[...slug].astro` to avoid a route collision. When adding another custom page, add its ID to that set.

### Blog

- The `post` collection points to `src/data/post/`, which doesn't exist in this repo, so the AstroWind blog routes (`src/pages/[...blog]/`) produce no posts.
- The writing shown on the site comes from `src/components/widgets/HashnodeLatest.astro`. It fetches the Hashnode **RSS feed** at build time and parses it with `fast-xml-parser`. It uses RSS because Hashnode's free GraphQL API was retired in May 2026. Posts update only when the site is rebuilt.

### Site content and config

- Site name, SEO defaults and blog toggles are in `src/config.yaml`. Header and footer links are in `src/navigation.ts`. The homepage is `src/pages/index.astro`.

## Gotchas

- In `astro.config.ts`, `astro-compress` runs with `csso: false` on purpose. csso drops Tailwind v4's `@media (width>=48rem)` range syntax, which breaks every `md:`/`lg:` class. Don't re-enable it.
- `astro-icon` includes all of `tabler` but only `hashnode` from `simple-icons`. To use another simple-icons icon, add it to the `include` list in `astro.config.ts`.
- Netlify sets `pretty_urls = false` and adds immutable caching for `/_astro/*` (`netlify.toml`).
