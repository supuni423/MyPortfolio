# Supuni Dissanayake — Portfolio

My personal portfolio, built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/).

🌐 **Live site:** [supuni-dissanayake.netlify.app](https://supuni-dissanayake.netlify.app)

## About

Information Technology undergraduate at the University of Moratuwa, specializing in full-stack development, UI/UX design, and AI-integrated applications. This site showcases my projects — including detailed case studies for Mentora, SmartClinic, AES Glove, and the Mentora Student App — along with my skills, education, and technical writing.

## Tech stack

- **Framework:** Astro 7
- **Styling:** Tailwind CSS v4
- **Content:** Astro Content Collections (Markdown)
- **Hosting:** Netlify
- **Blog integration:** live feed from my [Hashnode](https://supunihashnodedev.hashnode.dev) publication via RSS

## Development

```shell
npm install       # Install dependencies
npm run dev       # Start local dev server at localhost:4321
npm run build     # Build for production to ./dist/
npm run preview   # Preview the production build locally
npm run check     # Run astro check + ESLint + Prettier
npm run fix       # Auto-fix ESLint + Prettier issues
```
