SmartClinic is a full-stack clinic management system built for a private medical practice, covering patient records, appointments, consultations, prescriptions, and billing.

- Implemented JWT authentication and role-based access control for Doctor and Receptionist roles.
- Built an AI Assistant (Doctor-only) powered by the Gemini API for querying live clinic data through natural language.
